## 4. Multi-step / DLOAD smokes

Parser semantics checked first in `crates/solvix-io/src/parser.rs` (issue #26):
`*DLOAD` inside `*STEP`; gravity row is `GRAV, magnitude, dir1[, dir2][, dir3]` →
`(9.81, 0, -1)` is 9.81 m/s² pointing −Y (matches parser test
`dload_edges_grav_and_density_parse` and core test
`gravity_column_base_reactions_balance_weight`). `OP=NEW` on `*STEP` resets the
whole step accumulator *including* BCs (parser.rs:708); the load-swap idiom is
`*CLOAD, OP=NEW` inside step 2 — decks follow that.

### (a) Single-step gravity column (`/tmp/opencode/gravity_column.inp`)

CPS4 column 0.1 × 1.0 m, 5 elements, base fixed, `*DENSITY 7850`,
`*DLOAD GRAV, 9.81, 0.0, -1.0`. E scaled to 210e6 so the mm-displacement is
visible at 3 decimals (steel gives 1.8e-4 mm). CLI does not print reactions, so
the gate is exit 0 + `ok:true` + `max_disp_mm > 0`, per gate instructions.

```
{"ok":true,"job":"gravity_column","nodes":12,"elements":5,"iterations":10,
 "solver_method":"pcg","cond_estimate":4.062e8,"residual":8.470e-16,"solve_ms":1,
 "max_disp_mm":0.182,"max_von_mises_mpa":0.068,"outputs":["./gravity_column.vtu"]}
exit 0
```

Physics corroboration (not gated): analytical self-weight tip displacement
ρgL²/2E = 7850·9.81·1²/(2·210e6) = 0.183 mm vs 0.182 reported. Weight
ρAtLg = 7850·0.1·t·9.81 (t = section thickness) would be the reaction check if
reactions were exported.

### (b) Two-step load swap (`/tmp/opencode/two_step.inp`)

Same mesh; step 1: `*BOUNDARY` + `*CLOAD 11, 2, -1000`; step 2:
`*CLOAD, OP=NEW 11, 2, -2500`.

```
{"ok":true,"job":"two_step","nodes":12,"elements":5,"iterations":23,
 "solver_method":"pcg","cond_estimate":4.062e11,"residual":7.378e-11,"solve_ms":0,
 "max_disp_mm":0.002,"max_von_mises_mpa":0.025,"outputs":["./two_step.vtu"]}
exit 0
```

Final-state check: a reference deck with only the step-2 load
(`/tmp/opencode/ref_step2only.inp`, identical mesh) returns the same numbers —
iterations 23, residual 7.378e-11, max_disp 0.002 mm, von Mises 0.025 MPa —
so the final state equals the step-2 loads alone (OP=NEW dropped step 1).
